# 아공간 관리인 — starter art pack

기획서의 2D 탑다운 창고 정리 루프를 위한 편집 가능한 SVG 에셋입니다. 아직 Godot 프로젝트가 없어서 프로젝트 구조에 종속되지 않는 원본으로 구성했습니다.

## 포함 항목

- `player.svg`: 정면 방향 플레이어 임시 스프라이트
- `storage_room.svg`: 창고 방 배경과 바닥 장식
- `shelf.svg`, `crate.svg`: 배치 가능한 창고 설비 및 상자
- `items.svg`: 무기, 방어구, 물약, 재료, 광석, 보석, 주문서, 열쇠, 보물 상자, 상자 아이콘 아틀라스

## Godot 사용

SVG 파일을 `res://assets/` 아래로 복사한 뒤 Sprite2D의 Texture로 지정하면 됩니다. `items.svg`는 128×128 셀 5열×2행 아틀라스이며 Godot의 AtlasTexture에서 영역을 지정해 사용할 수 있습니다. 게임 내 픽셀 아트 스타일로 교체할 때도 파일 이름과 분류를 유지하면 데이터 연결이 쉽습니다.

## 스타일

짙은 남색 윤곽, 청록색 마법 조명, 따뜻한 나무와 황동을 사용한 아늑한 판타지 창고 콘셉트입니다. 현재 캐릭터는 방향별 애니메이션이 없는 정면 시안입니다.
