# 아공간 관리인 — starter art pack

기획서의 2D 탑다운 창고 정리 루프를 위한 편집 가능한 SVG 에셋입니다. 타일 규격과 픽셀 표현은 제공된 `kenney_tiny-dungeon.zip` 프리뷰에 맞췄습니다. 아직 Godot 프로젝트가 없어서 프로젝트 구조에 종속되지 않는 원본으로 구성했습니다.

## 포함 항목

- `tiles/floor_tiles.svg`: 16×16 바닥 타일 4종 아틀라스
- `tiles/shelf_empty.svg`: 높이 3칸, 비어 있는 선반
- `tiles/shelf_1_shelf.svg`: 한 칸에 물건이 놓인 선반
- `tiles/shelf_2_shelves.svg`: 두 칸에 물건이 놓인 선반
- `tiles/shelf_3_shelves.svg`: 세 칸 모두 물건이 놓인 선반
- `tiles/wall_tiles.svg`: 16×16 벽면/벽 끝/모서리/기둥 타일 6종
- `characters/player_blackhair.svg`: 검은 머리 남성 플레이어 4방향 걷기 시트
- `characters/player_blackhair_female.svg`: 검은 머리 여성 플레이어 4방향 걷기 시트
- `storage_room.svg`, `crate.svg`, `items.svg`: 기존 콘셉트 시안

## Godot 사용

바닥 아틀라스 셀은 16×16입니다. 선반 스프라이트는 32×48(타일 2칸 너비×3칸 높이), 투명 배경이며 네 상태 모두 같은 크기와 바닥 기준선을 사용합니다. Godot에서 SVG를 Texture로 지정하거나 같은 이름의 PNG로 변환해 사용할 수 있습니다. 선반 `Sprite2D` 기준점은 하단 중앙(16, 48)에 두면 바닥 타일에 맞춰 배치하기 쉽습니다.

벽 아틀라스는 16×16 셀 6개를 가로로 배치했습니다. 순서는 정면 벽, 윗면 벽, 왼쪽 끝, 오른쪽 끝, 바깥 모서리, 기둥입니다. 캐릭터 시트는 16×24 셀 4열×4행이며 행 순서는 아래/왼쪽/오른쪽/위입니다. 각 행은 걷기 사이클 4프레임입니다. `AnimatedSprite2D`에서 행별로 프레임 4개를 지정하면 됩니다. 발끝 기준선과 몸의 기준 위치는 프레임마다 일정하게 두고 팔과 다리만 교대로 움직이도록 구성했습니다.

선반 상태의 채움 단계는 아래에서부터 누적됩니다. 빈 선반은 아무 물건도 없고, 1/2/3칸 상태는 하단부터 차례로 채워집니다.

## 스타일

짙은 남색 윤곽, 차가운 회색 석재 바닥, 따뜻한 목재 선반을 사용한 픽셀 던전 창고 콘셉트입니다. 남녀 캐릭터는 Kenney roguelike 캐릭터의 픽셀 밀도와 맞춘 2등신 시안이며 옷 색과 머리 실루엣으로 구분했습니다.
