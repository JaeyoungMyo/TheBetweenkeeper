# 사용자 스토리 (User Stories)

**구성 방식**: 혼합 (US-2 D) = epic 으로 묶고, 각 epic 안은 플레이 흐름 순서
**문장 형식**: 표준 (US-3 A) — "[persona] 로서, [행동] 을 하고 싶다. [이유] 를 위해서"
**인수 조건 형식**: Given/When/Then 을 기본으로, 단순 확인은 체크리스트 (US-4 D)
**범위**: 전체 FR-01~31 (US-5 A)
**세분화**: 중간 단위, 약 20~30개 (US-6 B)
**시스템 스토리**: 저장 · 배포 · 설정만 별도 SYS 로 분리 (US-7 C)

**ID 규칙**: `US-NN` (사용자 스토리), `SYS-NN` (시스템 스토리), 인수 조건 `AC-NN-n`

---

## Epic 1. 아이템 정리

### US-01 신규 플레이어 튜토리얼
- **스토리**: 신규 플레이어로서, 튜토리얼에서 아이템 10개를 목록에서 선반으로 옮겨 보고 싶다. 조작과 규칙을 한 번에 익히기 위해서
- **관련 FR**: FR-02, FR-03, FR-29
- **인수 조건**
  - AC-01-1: Given 튜토리얼을 시작했을 때, When 화면을 보면, Then 아이템 10개가 목록에 표시된다
  - AC-01-2: Given 선반을 클릭했을 때, When 패널이 열리면, Then 목록의 아이템을 드래그해 적재할 수 있다
  - AC-01-3: Given 10개를 모두 적재했을 때, When 튜토리얼이 끝나면, Then 아이템 10개가 모두 `stored` 상태다
- 체크리스트: [ ] 튜토리얼 아이템 수가 10개다 [ ] 튜토리얼 중 다른 던전은 열리지 않는다

### US-02 아이템 목록을 항상 보며 정리
- **스토리**: 정리 플레이어로서, 들고 있는 아이템 목록을 화면에서 항상 보고 싶다. 무엇을 옮겨야 할지 놓치지 않기 위해서
- **관련 FR**: FR-02
- **인수 조건**
  - AC-02-1: Given 게임 중일 때, When 어떤 화면이든, Then 아이템 목록이 가려지지 않고 보인다
  - AC-02-2: Given 아이템 상태가 바뀌었을 때, When 목록을 보면, Then 바뀐 상태가 즉시 반영된다
- 체크리스트: [ ] 1280x720 에서 목록이 잘리지 않는다

### US-03 선반에 아이템 적재
- **스토리**: 정리 플레이어로서, 선반을 클릭해 열린 패널에 아이템을 드래그해 넣고 싶다. 종류별로 깔끔하게 보관하기 위해서
- **관련 FR**: FR-03, D-14
- **인수 조건**
  - AC-03-1: Given 선반 패널이 열렸을 때, When 목록의 아이템을 패널에 드롭하면, Then 아이템이 선반에 적재된다
  - AC-03-2: Given 패널이 닫혀 있을 때, When 목록에서 선반에 드래그하면, Then 적재되지 않는다
  - AC-03-3: Given 패널이 열려 있을 때, When X 버튼을 누르면, Then 패널이 닫힌다
- 체크리스트: [ ] 같은 선반을 다시 클릭하면 패널이 닫힌다

### US-04 맵에 아이템 버리기
- **스토리**: 정리 플레이어로서, 패널이 닫힌 상태에서 아이템을 맵 아무 곳에나 드롭하고 싶다. 필요 없는 아이템을 그 자리에 버리기 위해서
- **관련 FR**: FR-04, D-14
- **인수 조건**
  - AC-04-1: Given 패널이 닫혀 있을 때, When 아이템을 맵에 드롭하면, Then 드롭한 위치에 아이템이 놓인다
  - AC-04-2: Given 드롭이 끝났을 때, When 목록을 보면, Then 해당 아이템이 목록에서 빠진다
- 체크리스트: [ ] 벽 위에 드롭하면 벽 앞쪽으로 보정된다 (구현 시 확정)

### US-05 바닥 아이템 줍기
- **스토리**: 정리 플레이어로서, 바닥에 떨어진 아이템에 마우스를 올려 이름을 확인하고 클릭해서 줍고 싶다. 바닥의 물건을 빠르게 다시 정리하기 위해서
- **관련 FR**: FR-05, D-16
- **인수 조건**
  - AC-05-1: Given 바닥 아이템 위에 마우스를 올렸을 때, When 잠시 머무르면, Then 아이템 이름이 표시된다
  - AC-05-2: Given 아이템을 클릭했을 때, When 플레이어와 가까우면, Then 아이템이 목록에 들어온다
  - AC-05-3: Given 키보드 상호작용 키를 눌렀을 때, When 가까운 아이템이 있으면, Then 같은 방식으로 줍는다
- 체크리스트: [ ] 줍기 후 목록에 1개 추가된다 [ ] 이미 들고 있으면 줍지 못한다

### US-06 무게 초과 시 적재 거부
- **스토리**: 정리 플레이어로서, 시설의 최대 무게를 넘는 아이템을 놓으면 메시지가 뜨고 아이템은 손에 남기를 원한다. 무게 제한을 이해하기 위해서
- **관련 FR**: FR-06, FR-07, D-09
- **인수 조건**
  - AC-06-1: Given 선반의 현재 무게와 아이템 무게의 합이 최대를 넘을 때, When 적재를 시도하면, Then "무게 초과" 메시지가 표시된다
  - AC-06-2: Given 적재가 거부되었을 때, When 목록을 보면, Then 아이템이 그대로 들려 있다
  - AC-06-3: Given 선반에 여유가 있을 때, When 적재하면, Then 메시지 없이 적재된다
- 체크리스트: [ ] 메시지 문구가 한국어로 표시된다

### US-07 무게와 무관한 이동 속도
- **스토리**: 정리 플레이어로서, 무거운 아이템을 들어도 이동 속도가 같아서 정리에 집중하고 싶다. 속도 대신 아이템 개수와 칸 한도로 난이도를 느끼기 위해서
- **관련 FR**: FR-08
- **인수 조건**
  - AC-07-1: Given 가벼운 아이템을 들었을 때, When 이동하면, Then 기본 속도로 움직인다
  - AC-07-2: Given 무거운 아이템을 들었을 때, When 이동하면, Then 가벼운 아이템을 들었을 때와 같은 속도로 움직인다 (사용자 정정: 속도 무관)
  - AC-07-3: Given 아이템을 내려놓았을 때, When 이동하면, Then 여전히 같은 기본 속도다
- 체크리스트: [ ] 아이템 무게와 무관하게 이동 속도가 일정하다 (사용자 정정)

### US-08 벽과 시설에 막히는 이동
- **스토리**: 정리 플레이어로서, WASD 나 방향키로 방 안을 움직이되 벽과 시설에 막히고 싶다. 공간을 현실처럼 느끼기 위해서
- **관련 FR**: FR-01
- **인수 조건**
  - AC-08-1: Given 방향키 또는 WASD 를 누르면, When 벽 방향이면, Then 플레이어가 벽을 통과하지 않는다
  - AC-08-2: Given 선반 같은 시설과 부딪히면, When 계속 누르면, Then 시설을 통과하지 않는다
- 체크리스트: [ ] 대각선 이동에서도 벽을 통과하지 않는다

## Epic 2. 성장

### US-09 수납으로 EXP 얻기
- **스토리**: 정리 플레이어로서, 아이템을 정해진 자리에 수납할 때마다 EXP 를 얻고 싶다. 정리할수록 성장한다고 느끼기 위해서
- **관련 FR**: FR-10
- **인수 조건**
  - AC-09-1: Given 아이템을 수납했을 때, When 첫 수납이면, Then EXP 가 지급된다
  - AC-09-2: Given 같은 아이템을 다시 집었다 놓았을 때, When 수납하면, Then EXP 가 다시 지급되지 않는다
- 체크리스트: [ ] EXP 가 HUD 에 즉시 반영된다

### US-10 레벨업 증강 선택
- **스토리**: 정리 플레이어로서, 레벨업하면 증강 후보 중 하나를 고르고 싶다. 내 방식에 맞게 성장하기 위해서
- **관련 FR**: FR-11
- **인수 조건**
  - AC-10-1: Given 레벨업이 발생했을 때, When 증강 선택 화면이 열리면, Then 후보가 제시된다
  - AC-10-2: Given 증강을 골랐을 때, When 확인하면, Then 선택한 효과가 즉시 능력치에 반영된다
  - AC-10-3: Given 후보를 뽑을 때, When 같은 증강이 이미 제시되었으면, Then 한 화면에 중복되지 않는다
- 체크리스트: [ ] 증강 후보가 최소 2개 이상 제시된다

## Epic 3. 던전 흐름

### US-11 던전 전투 진행
- **스토리**: 정리 플레이어로서, 던전마다 전투 3~5회가 이어지고 전투가 끝날 때마다 아이템이 쏟아져 들어오는 것을 보고 싶다. 던전 진행을 실감하기 위해서
- **관련 FR**: FR-12, D-04
- **인수 조건**
  - AC-11-1: Given 던전이 시작되었을 때, When 전투 횟수를 확인하면, Then 3~5회 사이다
  - AC-11-2: Given 전투가 끝났을 때, When 다음 단계로 가면, Then 그 전투의 신규 아이템이 입고된다
- 체크리스트: [ ] 전투 번호가 화면에 표시된다

### US-12 던전 완료 판정
- **스토리**: 정리 플레이어로서, 아이템을 다 정리하지 못해도 전투가 끝나면 던전이 완료되는 것을 알고 싶다. 정리 속도에 따라 긴장감을 느끼기 위해서
- **관련 FR**: FR-13, D-15
- **인수 조건**
  - AC-12-1: Given 마지막 전투가 끝났을 때, When 아이템이 미정리 상태여도, Then 던전이 완료된다
  - AC-12-2: Given 던전 완료 시, When 화면이 바뀌면, Then 완료 결과가 표시된다
- 체크리스트: [ ] 완료 판정에 정리 상태가 포함되지 않는다

### US-13 30초 수면 중 정리
- **스토리**: 정리 플레이어로서, 던전 완료 후 용사가 30초 수면하는 동안 정리할 수 있기를 원한다. 쌓인 아이템을 줄일 시간을 얻기 위해서
- **관련 FR**: FR-14, D-15
- **인수 조건**
  - AC-13-1: Given 수면이 시작되었을 때, When 화면을 보면, Then 남은 시간 (30초) 이 표시된다
  - AC-13-2: Given 수면 중일 때, When 플레이어가 아이템을 정리하면, Then 정리가 정상 반영된다
  - AC-13-3: Given 30초가 지났을 때, When 시간이 끝나면, Then 상점 방문으로 넘어간다
- 체크리스트: [ ] 수면 시간이 설정값과 같다

### US-14 미정리 아이템 누적
- **스토리**: 정리 플레이어로서, 정리하지 못한 아이템이 다음 던전까지 남아 있기를 원한다. 정리가 늦어질수록 부담이 커지는 긴장감을 느끼기 위해서
- **관련 FR**: FR-15, D-15
- **인수 조건**
  - AC-14-1: Given 미정리 아이템이 있을 때, When 다음 던전이 시작되면, Then 그 아이템이 정리 목록에 남아 있다
  - AC-14-2: Given 다음 던전에서 새 아이템이 들어올 때, When 목록을 보면, Then 이전 미정리 아이템과 새 아이템이 함께 보인다
- 체크리스트: [ ] 미정리 아이템의 상태가 바뀌지 않는다

## Epic 4. 긴급 요청

### US-15 용사 긴급 요청 대응
- **스토리**: 정리 플레이어로서, 전투 중 용사가 요청한 아이템을 제한 시간 안에 찾아 전달하고 싶다. 용사를 도우며 보상을 받기 위해서
- **관련 FR**: FR-20, FR-22
- **인수 조건**
  - AC-15-1: Given 요청이 발생했을 때, When 요청 패널을 보면, Then 요청 아이템과 남은 시간이 표시된다
  - AC-15-2: Given 제한 시간 안에 요청 아이템을 전달했을 때, When 전달이 끝나면, Then 골드, EXP 또는 특별 보상이 지급된다
  - AC-15-3: Given 요청 아이템이 없을 때, When 요청이 생성되면, Then 요청 목록에서 제외되거나 예외 처리된다
- 체크리스트: [ ] 전투 중에도 요청이 발생한다

### US-16 요청 실패 누적과 게임오버
- **스토리**: 정리 플레이어로서, 요청을 실패하면 누적되고 3회에 도달하면 게임오버가 되는 것을 알고 싶다. 실패의 결과를 실감하기 위해서
- **관련 FR**: FR-21, D-06
- **인수 조건**
  - AC-16-1: Given 요청이 실패했을 때, When 실패가 확정되면, Then 누적 실패 수가 1 증가한다
  - AC-16-2: Given 누적 실패가 3회에 도달했을 때, When 판정하면, Then 게임오버 화면으로 전환된다
  - AC-16-3: Given 실패 종류가 다를 때, When 누적하면, Then 요청 종류와 무관하게 함께 센다
- 체크리스트: [ ] 게임오버 화면에 누적 실패 수가 표시된다

### US-17 요청 중 아이템 보호
- **스토리**: 정리 플레이어로서, 용사가 요청한 아이템은 실수로 판매되지 않기를 원한다. 요청을 확실히 완수하기 위해서
- **관련 FR**: FR-23, D-14
- **인수 조건**
  - AC-17-1: Given 아이템이 요청 대상일 때, When 판매를 시도하면, Then 판매가 거부된다
  - AC-17-2: Given 요청이 끝났을 때, When 아이템이 해제되면, Then 다시 판매할 수 있다
- 체크리스트: [ ] 예약 상태가 목록에 표시된다

## Epic 5. 상점

### US-18 던전 완료 후 상점 방문
- **스토리**: 정리 플레이어로서, 던전이 끝나면 수면 후 용사가 상점에 들르는 흐름을 보고 싶다. 던전 사이의 준비 과정을 실감하기 위해서
- **관련 FR**: FR-16, FR-17, D-18
- **인수 조건**
  - AC-18-1: Given 던전이 완료되었을 때, When 수면이 끝나면, Then 상점 방문 연출이 열린다
  - AC-18-2: Given 던전을 1개 완료할 때마다, When 상점이 열리면, Then 상점 이벤트가 정확히 한 번 열린다
- 체크리스트: [ ] 상점 방문 순서가 완료 → 수면 → 상점 이다

### US-19 판매 요청에 응하기
- **스토리**: 정리 플레이어로서, 용사가 요청한 아이템을 출력공간으로 옮겨 판매하고 싶다. 골드를 얻어 다음 준비를 하기 위해서
- **관련 FR**: FR-30, FR-23
- **인수 조건**
  - AC-19-1: Given 용사가 판매를 요청했을 때, When 요청 목록을 보면, Then 요청 아이템이 표시된다
  - AC-19-2: Given 요청 아이템을 출력공간으로 옮겼을 때, When 판매를 확정하면, Then 골드가 지급되고 아이템은 `sold` 상태가 된다
  - AC-19-3: Given 출력공간에 요청 외 아이템이 있을 때, When 판매를 확정하면, Then 그 아이템은 판매되지 않는다
- 체크리스트: [ ] 판매가가 아이템마다 다르다

### US-20 구매품 입력공간에 받기
- **스토리**: 정리 플레이어로서, 용사가 구매한 물건이 입력공간에 무작위로 쌓이는 것을 보고 싶다. 다음 던전의 준비물을 직접 정리하기 위해서
- **관련 FR**: FR-18, FR-31, D-18
- **인수 조건**
  - AC-20-1: Given 구매를 확정했을 때, When 수량만큼 아이템이 생기면, Then 입력공간에 무작위 위치로 쌓인다
  - AC-20-2: Given 구매가 끝났을 때, When 아이템을 보면, Then 모두 `incoming` 상태다
  - AC-20-3: Given 구매품 목록을 보면, When 가중치 구매를 적용했을 때, Then 품목과 수량이 가중치에 따라 정해진다
- 체크리스트: [ ] 입력공간이 비어 있지 않으면 구매 전 여유를 확인한다 (V-3, UG-5 답변에 따라 변경)

### US-21 골드 부족 시 구매 실패
- **스토리**: 정리 플레이어로서, 골드가 부족하면 구매가 실패하고 아무 아이템도 생기지 않기를 원한다. 돈 관리를 명확히 이해하기 위해서
- **관련 FR**: FR-19
- **인수 조건**
  - AC-21-1: Given 골드가 구매 비용보다 적을 때, When 구매를 확정하면, Then 구매가 실패한다
  - AC-21-2: Given 구매가 실패했을 때, When 결과를 확인하면, Then 골드와 아이템이 변하지 않는다
- 체크리스트: [ ] 실패 메시지가 표시된다

### US-22 시설 구매와 확장
- **스토리**: 정리 플레이어로서, 골드로 선반을 사거나 확장해서 최대 무게를 늘리고 싶다. 창고 공간이 부족할 때 해결하기 위해서
- **관련 FR**: FR-24
- **인수 조건**
  - AC-22-1: Given 골드가 충분할 때, When 시설을 구매하면, Then 골드가 차감되고 시설이 추가된다
  - AC-22-2: Given 시설을 확장했을 때, When 최대 무게를 확인하면, Then 값이 늘어난다
- 체크리스트: [ ] 확장 전후 최대 무게가 표시된다

## 시스템 스토리 (US-7 C)

### SYS-01 던전 완료 시 자동 저장
- **스토리**: 정리 플레이어로서, 던전이 끝날 때마다 자동으로 저장되기를 원한다. 게임을 종료해도 진행을 잃지 않기 위해서
- **관련 FR**: FR-25, NFR-03
- **인수 조건**
  - AC-SYS-01-1: Given 던전 완료 시, When 저장이 실행되면, Then 아이템 위치 · 상태, 골드, 시설, 성장, 던전 번호, 실패 수가 저장된다
  - AC-SYS-01-2: Given 저장 후 재실행했을 때, When 불러오면, Then 같은 상태로 복원된다
  - AC-SYS-01-3: Given 저장을 10회 왕복했을 때, When 아이템 수를 비교하면, Then 중복 생성이나 누락이 없다

### SYS-02 웹 세이브 내보내기 · 불러오기
- **스토리**: 정리 플레이어로서, 웹에서 세이브 파일을 내보내고 다시 불러오고 싶다. 브라우저 데이터가 지워져도 진행을 지키기 위해서
- **관련 FR**: FR-26, D-03, AD-8, AD-9
- **인수 조건**
  - AC-SYS-02-1: Given 내보내기를 누르면, When 파일이 생성되면, Then 브라우저에서 다운로드된다
  - AC-SYS-02-2: Given 파일을 불러올 때, When 서명이 맞으면, Then 복원된다
  - AC-SYS-02-3: Given 파일 내용이 바뀌었을 때, When 불러오면, Then 거부된다

### SYS-03 웹 배포
- **스토리**: 신규 플레이어로서, itch.io 에서 바로 웹으로 실행하고 싶다. 설치 없이 바로 시작하기 위해서
- **관련 FR**: NFR-06, NFR-07, NFR-08
- **인수 조건**
  - AC-SYS-03-1: Given zip 을 업로드했을 때, When "Play in browser" 를 누르면, Then 게임이 실행된다
  - AC-SYS-03-2: Given 웹 빌드를 만들 때, When 설정을 보면, Then 스레드를 쓰지 않고 Compatibility 렌더러를 쓴다

### SYS-04 화면과 언어 설정
- **스토리**: 신규 플레이어로서, 1280x720 화면과 한국어 UI 로 게임을 시작하고 싶다. 읽기 쉽고 화면이 깨지지 않기 위해서
- **관련 FR**: FR-27, FR-28, D-10, D-11
- **인수 조건**
  - AC-SYS-04-1: Given 창 크기를 바꾸면, When 비율을 유지하면, Then 화면 비율 16:9 가 유지된다
  - AC-SYS-04-2: Given 게임 UI 를 보면, When 텍스트를 확인하면, Then 한국어로 표시된다
