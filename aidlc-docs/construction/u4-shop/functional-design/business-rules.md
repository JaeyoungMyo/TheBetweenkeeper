# U4 상점 비즈니스 규칙 (Business Rules)

**unit**: U4 상점
**기준**: `business-logic-model.md`, `construction/plans/u4-shop-functional-design-plan.md` (FD-U4-1 ~ 11)

| ID | 규칙 | 근거 | 검증 방법 |
| --- | --- | --- | --- |
| BR-U4-01 | 상점은 던전 1 개 완료마다 정확히 한 번 열린다 | D-18, FR-17, AC-18-2 | 단위: 완료 1회 → 상점 1회 |
| BR-U4-02 | 상점은 판매 → 구매 순서로 진행한다. 판매 골드를 구매에 쓸 수 있다 | D-18, 기획서 9.5 | 단위 |
| BR-U4-03 | 판매 요청 목록은 상점 열림 때 창고 아이템 (선반 · 바닥 · 들고 있는 것) 에서 무작위로 정한다. 던전 1 = 2개 | FD-U4-3 A, FR-30, AC-19-1 | 단위: 후보 없으면 0개 |
| BR-U4-04 | 판매 확정 시 출력공간의 요청 아이템만 판매한다 | AC-19-2 | 단위 |
| BR-U4-05 | 판매가는 U2 규칙 (무게 × 10, 판매가 보너스 증강) 을 쓴다. 향후 아이템별 `base_price` 로 바꾼다 | FD-U4-4 A (향후 B) | 단위 |
| BR-U4-06 | 출력공간의 요청 외 아이템은 판매하지 않고 맵 어딘가로 자동 이동한다 | FD-U4-5 X, AC-19-3 | 단위: 요청 외 아이템 판매 안 됨, 위치 변경 |
| BR-U4-07 | 구매 품목은 가중치 추첨으로 정한다. 방문마다 정해진 개수를 뽑는다 (던전 1 = 4개). 같은 품목 중복 가능 | FD-U4-6 A, FR-18, AC-20-3 | PBT: 뽑은 개수 = 정해진 개수 |
| BR-U4-08 | 품목을 뽑을 때마다 골드를 차감한다. 골드가 부족하면 그 품목만 건너뛰고 메시지를 띄운다 | FD-U4-7 B, AC-21-1, AC-21-2 | 단위: 부족 시 골드와 아이템 불변 |
| BR-U4-09 | 구매품은 입력공간 없이 맵에 무작위 위치로 떨어진다 (incoming) | FD-U4-1 C, FD-U4-8 X, AC-20-1, AC-20-2 | 단위: 상태 incoming |
| BR-U4-10 | 구매품은 구매 수량만큼 아이템 인스턴스를 만든다 | FR-31, AC-20-1 | 단위: 수량 = 인스턴스 수 |
| BR-U4-11 | 구매품은 다음 던전의 신규 아이템으로 들어온다. 던전의 무작위 입고 (U3) 와는 별도 경로다 | FD-U4-9 B, D-18 | 단위 |
| BR-U4-12 | 출력공간은 용량 제한이 없고, 아이템을 하나씩 넣는다 | FD-U4-2 A | 단위 |
| BR-U4-13 | 대량 상자 (상자 개념) 는 만들지 않는다 | FD-U4-10 A | 해당 없음 (범위 제외) |
| BR-U4-14 | 무기 · 방어구 구매는 POC 에서 제외한다 | FR-18 | 데이터 검토 |
