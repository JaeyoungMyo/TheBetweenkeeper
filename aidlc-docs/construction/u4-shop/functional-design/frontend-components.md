# U4 상점 화면 구성 — 변경 반영본

- **판매 퀘스트 패널**: U3 긴급 요청 패널과 같은 형태. 줄마다 `품목 (판매/필요)`, 남은 시간, 완료 줄 표시. 위치는 왼쪽 아래 (기존 퀘스트 패널과 같은 자리)
- **출력공간**: 창고 방 안 고정 위치 (전달 선반과 같은 조작: 가까이 가서 클릭 → 1 키 또는 드래그로 1개씩)
- **구매 패널**: 구매 품목 목록, 비용, 골드 부족 줄 흐리게. 구매는 판매 퀘스트가 끝나면 자동 진행
- **결과 메시지**: "판매 성공! 골드 +N, EXP +M" / "판매 실패" / "구매 완료: 품목 · 개수"
- 연출은 후순위 (FD-U4-11 A)
