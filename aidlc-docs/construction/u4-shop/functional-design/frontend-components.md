# U4 상점 화면 구성 (Frontend Components)

**unit**: U4 상점
**기준**: FD-U4-11 A (기능 중심 패널, 연출은 후순위)

## 컴포넌트
- `ShopView` (상점 패널): 판매 요청 목록, 구매 목록, 골드, 확정 버튼
  - 판매 요청 목록: 아이템 이름과 판매가 표시 (AC-19-1)
  - 구매 목록: 품목, 비용, 수량 표시. 골드가 부족하면 해당 줄을 흐리게 표시 (US-21)
  - 확정 버튼 2개: "판매 확정", "구매 확정" (또는 순서대로 한 번에 확정 — Code Generation 에서 정함)
- 출력공간: 맵 안 고정 위치 한 곳. 아이템을 하나씩 넣는다 (전달 선반과 같은 조작)
- 골드 표시: 상단 HUD 와 같이 실시간 갱신 (기존 `EconomyManager.gold_changed`)

## 흐름
1. 던전 완료 → 수면 → 상점 열림 (ShopView 표시)
2. 판매 요청 목록 확인 → 해당 아이템을 출력공간에 넣기
3. "판매 확정" → 골드 증가, 요청 아이템 삭제, 요청 외 아이템은 맵에 자동 이동
4. 구매 목록 확인 → "구매 확정" → 골드 차감 (품목별), 구매품이 맵에 떨어짐
5. 상점 닫기 → 다음 던전 시작

## 검증 규칙 (화면)
- 판매는 요청된 아이템에만 적용된다 (BR-U4-04)
- 골드 부족 메시지는 구매 확정 후 바로 보인다 (BR-U4-08)

## 연동 지점
- ShopFlow → EconomyManager (판매가, 골드 차감)
- ShopFlow → ItemManager (아이템 생성, sold 처리, 자동 이동)
- DungeonManager (U3) → ShopFlow (SHOP_HANDOFF 신호)
