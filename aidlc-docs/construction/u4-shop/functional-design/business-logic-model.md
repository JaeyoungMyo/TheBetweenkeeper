# U4 상점 비즈니스 로직 모델 (Business Logic Model) — 변경 반영본

**unit**: U4 상점 (Shop)
**기준**: `construction/plans/u4-shop-functional-design-plan.md` (FD-U4-1 ~ 11), 사용자 변경 요청 (판매 = 퀘스트, 잡템 · 장비 판매, 직업별 판매 예정)

던전 1개를 완료하면 상점이 열립니다. 상점은 **판매 퀘스트** (출력공간) 와 **구매** 두 단계입니다.

---

## 1. 상점 흐름 (ShopFlow)

```
[던전 완료 → 수면 30초 (U3)]
   │ SHOP_HANDOFF 신호
   ▼
[판매 퀘스트 SELL_QUEST]  ← 퀘스트처럼 발생. 길게 주는 시간, 많은 수량, 높은 EXP
   │ 성공: 줄을 모두 채움 → 필요 개수만큼 판매 (골드 + EXP 지급)
   │ 실패: 시간 초과 → 출력공간 아이템 그대로 남음 (상점 종료 시 맵으로 이동)
   ▼
[구매 BUY]  ← 판매 퀘스트가 끝나면 자동. 가중치 추첨, 품목마다 골드 차감, 맵에 떨어짐
   ▼
[상점 닫힘 CLOSED] → 다음 던전 준비 (U3 시작)
```

## 2. 판매 퀘스트 (SellQuest)

- 퀘스트 구조는 U3 긴급 요청과 같습니다 (줄 = 품목 × 필요 개수, 전달 수 · 완료 표시 · 초과분 유지).
- **출력공간**: 창고 방 안 고정 위치 (전달 선반과 같은 조작, 아이템을 하나씩 넣음). 용량 제한 없음.
- **판매 가능 품목**: 창고의 잡템과 장비 대부분 (선반 · 바닥 · 들고 있는 것 중에서 줄 후보를 고름). 제외: 물약 (회복약 등 소모품) — 초기 가정, 확인 필요.
- **수량**: 긴 퀘스트. 던전 1 = 12개 (초기값, 던전마다 늘어남). 줄 수는 1~3.
- **시간**: 길게. 던전 1 = 120초 (초기값).
- **보상**: 판매된 아이템의 판매가 합계만큼 골드 + **EXP 많이** (던전 1 = 80, 초기값).
- 성공 시 줄의 필요 개수만큼만 판매 (sold). 초과분은 출력공간에 남음.
- 실패 시 출력공간 아이템은 삭제하지 않음 (판매 안 됨). 상점 종료 시 맵 어딘가로 자동 이동 (FD-U4-5 X).
- **직업별 판매 (예정)**: 용사 직업이 정해지면 "자기 장비가 아닌 장비 전부" 를 판매 대상으로 확장합니다. 지금은 잡템 · 장비 대부분입니다.

## 3. 구매 (BuyFlow)

- 방문마다 가중치 추첨으로 품목 4개 (던전 1). 같은 품목 중복 가능 (BR-U4-07).
- 품목마다 골드 차감. 부족하면 그 품목만 건너뜀 (FD-U4-7 B).
- 구매품은 맵에 무작위 위치로 떨어짐 (`incoming`). 입력공간 없음 (FD-U4-8 X).
- 구매품은 다음 던전의 신규 아이템으로 들어옴 (별도 경로, FD-U4-9 B).

## 4. 열린 항목
1. 물약 (회복약) 을 판매 대상에서 뺄지 확인 (초기 가정)
2. 아이템별 판매가 (`base_price`) — 향후 (FD-U4-4)
3. 던전 2 이후 수량 · 시간 · EXP 값 (데이터)
4. 직업 도입 후 판매 규칙 (자기 장비 제외)
