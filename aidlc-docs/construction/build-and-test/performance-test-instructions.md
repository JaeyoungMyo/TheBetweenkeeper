# 성능 테스트 안내 (Performance Test Instructions)

## 요구사항
- NFR-01: 아이템 200개, 창고 1개 기준 60 FPS 이상 (기준 PC 사양은 테스트에서 확정, 가정 A-02)
- NFR-02: 웹 첫 화면 10초 이내, 입력 응답 100ms 이내 (가정 A-03)

## 상태: 보류 (사용자: 기준 PC 사양을 모름, 나중에 정함. 데스크톱만 진행)
- 헤드리스 실행은 렌더링을 하지 않아 FPS 를 잴 수 없다.
- 기준 PC 사양이 아직 정해지지 않았다 (A-02).
- 웹 빌드가 아직 없어 NFR-02 를 잴 수 없다.

## 수동 확인 방법 (집에서)
1. 데스크톱에서 게임을 실행하고 Godot 에디터의 Monitor (FPS) 를 켠다.
2. 아이템을 200개 생성 (F1 디버그 메뉴 "아이템 10개 생성" 을 20번) 하고 창고 방에서 움직인다.
3. FPS 가 60 아래로 떨어지지 않는지 본다. 기록 양식은 `TEST.md` 의 "발견한 문제 기록" 을 쓴다.
