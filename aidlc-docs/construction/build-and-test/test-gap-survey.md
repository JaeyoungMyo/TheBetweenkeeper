# 테스트 누락 조사 결과 (서브에이전트 2개, 읽기 전용)

## 발견하고 고친 문제
- 가격표: 선반 5~6번째 칸 가격 행이 없어 칸 구매 시 오류 가능 → 행 추가, 범위 밖 인덱스는 -1 반환
- shelf_price(0) 이 마지막 가격을 돌려주던 문제 → -1
- bag_price 범위 검사 보강
- 증강 선택 대기 (pending_choices) 가 저장되지 않던 문제 → 저장 · 복원 추가
- 저장 형식 검사 없음 → 버전과 필수 키 검사 추가, 잘못된 저장은 새 게임으로 처리
- 새 게임 시 튜토리얼 완료 · 상점 방문 수가 남던 문제 → 초기화
- DungeonFlow.finish_battle 상태 가드 없음 → 전투 중이 아니면 무시

## 추가한 테스트
- test_edge_cases.gd: 가격 범위, 판매가 폴백, EXP 음수, 증강 대기 저장, 빈 인벤토리, 판매된 아이템 제외, 형식 검사, 흐름 가드, 전투 수 상한, 퀘스트 비활성 틱
- test_continue_flow.gd: 던전 완료 저장 → 상점, 상점 완료 저장 → 다음 던전, 손상 저장 → 새 게임
