# U5 저장 · 플랫폼 비즈니스 로직 모델

**기준**: `construction/plans/u5-save-platform-functional-design-plan.md` (FD-U5-1 ~ 11)

## 1. 저장 흐름 (SaveService)
```
[던전 완료] ──▶ 저장 (지점: 던전 완료)
[상점 완료] ──▶ 저장 (지점: 상점 완료)
[게임오버] ──▶ 저장 파일 삭제 (새 게임)
```
- 저장은 자동으로만 한다. 수동 저장 버튼은 없다 (FD-U5-1 B).
- 저장 내용: 던전 번호 · 완료 횟수, 골드, 레벨 · EXP, 증강 · 능력치, 아이템 인스턴스 (위치 · 상태), 선반 (종류 · 위치 · 칸 수), 실패 횟수, 튜토리얼 완료 여부, 상점 방문 횟수 (FD-U5-11 A).
- 진행 중 퀘스트 · 판매 퀘스트는 저장하지 않는다 (FD-U5-7 A). 복원 후 전달 선반 아이템은 그대로 남는다.

## 2. 복원 흐름 (LoadService)
- 실행 시 저장 파일이 있으면 불러온다. 서명 (HMAC) 이 맞지 않으면 거부하고 새 게임을 시작한다 (AC-SYS-02-3 과 같은 기준).
- 복원 지점은 마지막 저장 지점이다. 던전 완료 저장이면 수면 · 상점 직전부터, 상점 완료 저장이면 다음 던전 시작 전부터 다시 시작한다 (FD-U5-6 B).
- 복원 시 아이템 수와 상태가 저장 당시와 같아야 한다. 중복 생성 · 누락 없음 (NFR-03, AC-SYS-01-3).

## 3. 보호 (SaveCodec)
- JSON 을 암호화한 뒤 HMAC-SHA256 서명을 붙인다 (FD-U5-3 B, AD-8, AD-9).
- 웹에서 암호화가 지원되지 않으면 서명만 쓴다 (V-1 미결, Build 단계에서 확인).
- HMAC 키는 빌드 시 상수로 주입한다 (FD-U5-4 A, V-4).

## 4. 웹 저장
- 웹도 `user://` 경로를 쓰며, 브라우저 저장소에 보관된다 (FD-U5-2 A).
- 파일 내보내기 · 불러오기 (SYS-02) 는 이번 범위에서 제외한다 (FD-U5-5 B). 브라우저 데이터가 지워지면 진행도 사라진다는 안내를 넣는다 (기획서 Phase 10).

## 5. 화면 · 언어 설정
- 해상도 1280x720 고정, 창 크기가 바뀌면 비율 유지 (FR-27).
- 설정 메뉴에 전체 화면 전환 버튼 (FD-U5-9 B).
- 설정 메뉴에 언어 항목 (한국어만 선택 가능, FD-U5-10 B). 영어는 MVP 이후.
