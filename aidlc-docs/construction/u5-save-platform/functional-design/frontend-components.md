# U5 저장 · 플랫폼 화면

- **설정 패널** (F2 또는 메뉴 버튼): 전체 화면 전환 (BR-U5-10), 언어 (한국어 고정, BR-U5-11). 전체 화면 전환은 데스크톱 우선, 웹은 브라우저 정책을 따른다.
- **저장 안내**: 저장 완료 시 짧은 메시지 "저장됨". 브라우저 데이터가 지워지면 진행이 사라진다는 안내를 설정 패널에 적는다.
- **게임오버 화면**: 새 게임 버튼 (기존) 을 누르면 저장 파일을 삭제하고 시작한다 (BR-U5-07).
- **시작 화면 (복원)**: 저장 파일이 있으면 "이어하기 / 새 게임" 중 고르는 버튼을 둔다. 서명이 틀리면 "저장 파일이 손상되어 새 게임으로 시작합니다" 메시지.
