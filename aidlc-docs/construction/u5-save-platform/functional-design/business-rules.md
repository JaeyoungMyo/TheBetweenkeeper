# U5 저장 · 플랫폼 비즈니스 규칙

| ID | 규칙 | 근거 | 검증 |
| --- | --- | --- | --- |
| BR-U5-01 | 던전 완료와 상점 완료 시점에 자동 저장한다 | FD-U5-1 B, FD-U5-6 B, FR-25 | 단위: 두 지점에서 저장 호출 |
| BR-U5-02 | 수동 저장 버튼은 없다 | FD-U5-1 | 수동 |
| BR-U5-03 | 저장 파일은 암호화 후 HMAC-SHA256 서명을 붙인다. 웹에서 암호화가 안 되면 서명만 쓴다 | FD-U5-3 B, V-1 | PBT: 왕복 후 동일, 1바이트 변조 시 거부 |
| BR-U5-04 | HMAC 키는 빌드 시 상수로 주입하고 저장 파일에 두지 않는다 | FD-U5-4 A, V-4 | 코드 검사 |
| BR-U5-05 | 서명이 맞지 않으면 저장을 거부하고 새 게임으로 시작한다 | AC-SYS-02-3 (기준 적용) | 단위 |
| BR-U5-06 | 진행 중 퀘스트 · 판매 퀘스트는 저장하지 않는다. 복원 후 진행 중 퀘스트는 없다 | FD-U5-7 A | 단위 |
| BR-U5-07 | 게임오버 시 저장 파일을 삭제한다. 다음 실행은 새 게임 | FD-U5-8 A | 단위 |
| BR-U5-08 | 저장 · 복원을 반복해도 아이템 수와 상태가 같다 (중복 · 누락 없음) | NFR-03, AC-SYS-01-3 | PBT: 10회 왕복 |
| BR-U5-09 | 웹 내보내기 · 불러오기는 이번 범위에서 제외한다. 브라우저 저장소만 쓴다 | FD-U5-5 B | 해당 없음 (범위 제외) |
| BR-U5-10 | 해상도는 1280x720 고정, 창 크기가 바뀌면 비율을 유지한다. 전체 화면 전환 버튼을 둔다 | FD-U5-9 B, FR-27 | 수동 |
| BR-U5-11 | 설정 메뉴의 언어는 한국어만 선택할 수 있다 | FD-U5-10 B, FR-28 | 수동 |
| BR-U5-12 | 웹과 데스크톱 모두 Compatibility 렌더러, 스레드 미사용 | NFR-07, NFR-08 | 프로젝트 설정 확인 |
