# U1 창고 · 조작 비즈니스 로직 모델 (Business Logic Model)

**unit**: U1 창고 · 조작
**기준**: `construction/plans/u1-storage-controls-functional-design-plan.md` (FD-U1-1 ~ 7, 해석 FD-A1), `inception/application-design/unit-of-work.md`, `user-stories/stories.md` (US-01 ~ US-08)

## 1. 핵심 흐름

### 1-1. 줍기 (US-05)
1. 플레이어가 바닥 아이템에 마우스를 올린다 → 이름 표시 (호버 거리 64px)
2. 클릭 또는 상호작용 키를 누른다
3. 조건 검사: 플레이어 거리 ≤ 48px, 운반 수 < 한도 (D-20)
4. 통과하면 아이템 상태 `incoming` → `carried`, 위치는 플레이어 손으로 이동
5. 실패하면 상태 변화 없음, 이유를 짧게 알림

### 1-2. 선반 적재 (US-03, US-06)
1. 선반 클릭 → 선반 패널 열림 (`ShelfPanel`), 패널 안에 칸 3개가 보임 (FD-U1-7)
2. 목록의 아이템을 패널 칸으로 드래그 → 드롭
3. 칸 선택: 드롭한 칸의 무게 합 + 아이템 무게 ≤ 칸 한도 (12)
4. 시설 검사: 선반 전체 무게 + 아이템 무게 ≤ 선반 최대 (칸 수 3 × 12 = 36) (FD-A1)
5. 통과하면 아이템 상태 `carried` → `stored`, 칸에 배정
6. 실패하면 "무게 초과" 메시지 표시 후 아이템을 **플레이어 발 아래**에 떨어뜨림 (FD-U1-6), 상태 `carried` → `incoming`, 위치는 플레이어 좌표

### 1-3. 맵 드롭 (US-04)
1. 패널이 닫혀 있는 상태에서 목록의 아이템을 맵에 드롭
2. 아이템은 **플레이어 발 아래**에 놓인다 (FD-U1-6 X 답변). 드롭 위치와 무관
3. 상태 `carried` → `incoming`, 목록에서 제거

### 1-4. 선반 패널 밖에서 꺼내기
- 패널 안의 아이템을 목록으로 드래그하면 꺼낸다. 상태 `stored` → `carried`
- 꺼낸 뒤 시설 무게 합에서 제외

### 1-5. 이동 속도 (US-07, FR-08 정정)
1. 이동 속도는 손에 든 아이템의 무게와 무관하게 항상 일정하다 (사용자 정정)
2. 무게 등급은 분류 정보로만 쓰며 속도 계산에 넣지 않는다
3. 실제 이동 속도 = 기본 이동 속도 (PlayerData.move_speed)

### 1-6. 벽 · 시설 충돌 (US-08)
- 플레이어는 벽과 시설 콜리전을 통과하지 않는다
- 이동은 WASD 와 방향키 모두 허용

## 2. 상태 전환 (FR-09)

| 현재 | 이벤트 | 다음 | 조건 |
| --- | --- | --- | --- |
| `incoming` | 줍기 | `carried` | 거리 ≤ 48px, 운반 여유 있음 |
| `carried` | 선반 적재 | `stored` | 칸 한도와 시설 한도 통과 |
| `carried` | 선반 적재 실패 | `incoming` | 무게 초과 → 플레이어 발 아래 |
| `carried` | 맵 드롭 | `incoming` | 항상 성공, 발 아래 |
| `stored` | 패널에서 꺼냄 | `carried` | 운반 여유 있음 |
| `stored` · `incoming` | (U1 범위 밖) | `requested` · `reserved` · `sold` | U3 · U4 가 담당 |

## 3. 판정 규칙 요약

| 규칙 | 값 | 출처 |
| --- | --- | --- |
| 칸 무게 한도 | 12 (고정) | FD-U1-7 정정 답변 |
| 칸 수 (기본) | 3 | Q8, FD-U1-7 |
| 선반 최대 무게 | 칸 수 3 × 12 = 36 | FD-A1 정정 |
| 운반 개수 | 가방 1~5 × 배수 1~3 | D-20 |
| 줍기 거리 | 48px | FD-U1-4 (A) |
| 호버 거리 | 64px | FD-U1-4 (C) |
| 무게 등급 | 경량 ≤2, 중량 ≤4, 고중량 >4 | 사용자 확인 (분류 정보) |
| 속도 배율 | 없음 (무게와 무관하게 일정) | 사용자 정정 |
| 무게 경계 | 합계 ≤ 한도 이면 허용 | FD-U1-1 (A) |
| 낙하 위치 | 플레이어 발 아래 | FD-U1-6 (X 답변) |
| 낙하 상태 | `incoming` | FD-U1-5 (A) |

## 4. 예외 · 경계 사례

- 손에 든 아이템이 있는데 줍기 → 실패. 이유 메시지 표시
- 칸 3개가 모두 가득 찬 상태에서 적재 → "무게 초과" 메시지 후 낙하 (FR-07)
- 같은 아이템을 같은 칸에 두 번 적재 → 중복 수납 방지: 상태가 이미 `stored` 이면 적재 거부
- 시설 확장 (U2 소관) 으로 칸 수가 늘면 시설 최대 무게가 함께 늘어난다 (FD-A1)
- 아이템 무게는 정수 1, 2, 3, 4, 6 (사용자 정정 답변). 12 는 동일 아이템으로 정확히 맞출 수 있음 (예: 6+6, 4+4+4, 1×12)
