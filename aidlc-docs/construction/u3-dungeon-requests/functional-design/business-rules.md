## 금지 규칙 (Invariants)
- 요청 ACTIVE 는 0 또는 1 건이다 (BR-U3-07).
- 던전 완료 상태에서 전투가 남아 있지 않다 (BR-U3-02).
- reserved 아이템은 판매되지 않는다 (BR-U3-10).
- F 는 0 이상 3 이하다. 3 에 도달하면 게임오버로 고정된다 (BR-U3-11).
- 수면 중에는 요청 상태가 PENDING → ACTIVE 로 넘어가지 않는다 (BR-U3-12).
