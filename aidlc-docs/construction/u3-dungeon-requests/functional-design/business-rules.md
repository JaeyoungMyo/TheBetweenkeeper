## 금지 규칙 (Invariants)
- 진행 중 퀘스트는 0 또는 1 건이다 (BR-U3-07).
- 줄의 전달 수는 필요 개수를 넘지 않는다 (BR-U3-09).
- 성공 시 삭제 개수 = 줄 필요 개수의 합이다 (BR-U3-12).
- 실패 시 전달 공간 아이템은 삭제되지 않는다 (BR-U3-13).
- F 는 0 이상 3 이하다. 3 에 도달하면 게임오버로 고정된다 (BR-U3-17).
- 수면 중에는 퀘스트가 생성되지 않는다 (BR-U3-20).
